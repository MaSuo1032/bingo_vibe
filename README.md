# 🎰 BINGO BINGO 對獎與統計系統

以 Streamlit 製作的台灣彩券 BINGO BINGO 輔助工具：查看近期開獎、今日開獎統計、虛擬下注、代管實體彩券自動對獎、快速對獎，以及選號策略回測。

> ⚠️ 每期開獎都是獨立的隨機事件，本工具的統計與選號策略**無法提高中獎機率**。各玩法理論回報率約 50%～65%，請量力而為。未滿 18 歲不得購買彩券。

## 功能

| 頁籤 | 說明 |
|---|---|
| 📊 開獎紀錄 | 近 3 天開獎號碼與超級獎號 |
| 🔥 今日開獎統計 | 出現次數排行、遺漏期數、區間分佈、大小單雙、尾數 |
| 🎫 虛擬下注 & 實體匯入 | 用選號工具箱模擬下注，或登錄已購買的實體彩券讓系統自動對獎 |
| 📋 我的投注紀錄 | 自動對獎、損益總覽、明細 |
| 🎯 單次實體對獎 | 依購買時間或期號一次對多期，不留紀錄 |
| 🧪 策略回測 | 用歷史資料比較各選號策略與機選的實際回報率 |

派彩依台彩 API 回傳的**各期官方獎金**計算，限時加碼活動會自動反映；缺少資料時才使用標準獎金表。

## 執行

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 資料儲存

| 檔案 | 內容 |
|---|---|
| `bingo_bets_history.json` | 各暱稱的投注紀錄 |
| `bingo_users.json` | 各暱稱的密碼雜湊 (PBKDF2-SHA256，不存明文) |

- 預設存放在目前工作目錄；設定環境變數 `BINGO_DATA_DIR` 可改到其他目錄 (例如持久化磁碟)。
- Streamlit Community Cloud 等平台的檔案系統是暫時性的，重新部署後檔案會消失，正式使用請把 `BINGO_DATA_DIR` 指向持久化儲存。
- 寫入採「暫存檔 + 原子替換」並加鎖；檔案損毀時會停止寫入並顯示錯誤，避免覆蓋掉其他玩家的資料。
- 未設定密碼的暱稱任何人都能存取，可在側欄輸入密碼後按「🔒 鎖定此暱稱」。

## 專案結構

```
app.py              # Streamlit 主程式，每個頁籤一個 render_* 函式
bingo/
  scraper.py        # 台彩 API 抓取與快取
  logic.py          # 獎金、對獎、統計、選號策略、回測 (不依賴 Streamlit)
  storage.py        # 投注紀錄與密碼的檔案儲存
  ui.py             # 樣式與號碼球
tests/              # pytest 單元測試
```

## 測試

```bash
pip install -r requirements-dev.txt
pytest
```
